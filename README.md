# animalrecord-release-notes

Animal-Record ist ein Protokoll-Tool für die Aufnahme von Phänotypen anwendbar für alle landwirtschaftlich genutzten Tiere.
- Leistung
- Krankheiten
- Behandlungen

Die Nutzung ist auch offline möglich.
